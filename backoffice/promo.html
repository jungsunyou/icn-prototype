  • 🔒 개인정보 최소화 지침 — 조회는 티켓번호 기준, 표시는 닉네임. 실명·전화번호 등 개인정보 노출 금지(개인정보보호법). 전 화면 공통 적용
  • 프로모션 vs 쿠폰 — 프로모션=정책(할인·적용상품·자격·활성기간), 쿠폰=발급 단위(명·이미지·설명·사용기간)
  • 활성 기간(프로모션) — 발급·운영 가능 기간
  • 사용 기간(쿠폰) — 발급 쿠폰 사용 가능 기간 · 시작·종료일 지정
  • 발급 방식 — 난수번호 생성 · 프로모션 코드(입력형) · 수동(대상 지정, 발송 방법 선택)
  • 코드 자동 생성 — 프로모션 코드·개별 쿠폰코드는 시스템 자동 생성 유니크 키(외부 매핑). 단, 입력형 redemption 코드(예: WELCOME2026)만 관리자가 지정
  • 교환쿠폰 사용처리 — 크루 현장 처리 · 프로모션 vs 별도 운영 위치 검토 중(킵)
  • 유형 — 일반·신분·교환. 직권할인은 OS 전용(별도)
  • 자격 할인 — 신분·지역·크루 1개만 단독
  • 난수 쿠폰 — 중복 없는 무작위 코드 대량 발급
  • 크루 승인코드 — 크루별 일일 자동 생성 · "크루 확인 필요" 프로모션 적용 시 입력 · 승인 크루는 주문에 기록
  • 선물 — 취소 없음 · 수신 대기 회수·삭제 안 함
  • 적용 상품 — 연결은 프로모션 소유, 상품 화면은 읽기
  • 정산 연계 — 프로모션 ID·유형·명만 제공
