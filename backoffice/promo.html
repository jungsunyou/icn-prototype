공통
  • lock 개인정보는 최소한으로 — 티켓번호로 찾고 닉네임만 보여줍니다. 실명·전화번호는 보여주지 않습니다(개인정보보호법). 모든 화면에 똑같이 적용합니다. 화면의 값은 예시입니다.
  • 화면 구조 — 프로모션 목록 → 프로모션 상세 → 그 아래 쿠폰 → 쿠폰 상세에서 쿠폰 설정과 상태를 봅니다. 발급 · 사용 집계와 발급된 쿠폰 목록은 쿠폰·이용 조회 탭의 쿠폰 상세에서 봅니다.
  • 프로모션과 쿠폰의 차이 — 프로모션은 '어떤 할인을, 어떤 상품에, 누구에게' 정하는 규칙이고, 쿠폰은 그 규칙으로 실제로 나눠주는 것(이름·이미지·기간)입니다.
  • ID · 번호는 자동으로 — 프로모션 ID와 쿠폰 번호는 시스템이 겹치지 않게 만듭니다. 고객이 입력하는 공용 코드(예: WELCOME2026)만 관리자가 정합니다.
  • 정산 연동 — 정산에는 프로모션 ID·유형·이름만 넘깁니다.
  • 보라색 표시 — 아직 정하지 않은 항목은 화면 안에 보라색으로 표시했습니다.
프로모션
  • 프로모션 유형 — 일반·신분·제휴·교환 네 가지입니다. 신분은 쿠폰 없이 자동 할인되고, 제휴는 쿠폰(프로모션 코드 포함)으로 발급됩니다. 현장 직원 재량 할인(직권할인)은 OS에서만 따로 다룹니다.
  • 자격 — 신분·제휴 할인은 자격을 골라 만듭니다. 자격 등록은 신분·제휴 탭에서만 하고, 프로모션에서는 고르기만 합니다. 같은 자격을 여러 프로모션에서 다시 쓸 수 있습니다.
  • 신분 할인 — 신분·지역·크루 할인은 한 번에 하나만 적용됩니다. 다른 할인과 같이 쓸 수 없습니다. 단, OS에서는 예외로 직권할인과 함께 적용할 수 있습니다. 신분 할인은 쿠폰이 없어 쿠폰 칸이 없습니다.
  • 교환 — 상품 교환권입니다. 할인 금액이 없고, 교환 상품은 쿠폰을 만들 때 꼭 하나 고릅니다.
  • 적용 상품 — 여러 개 고를 수 있고, 연결은 프로모션에서만 합니다. 상품 관리 화면에서는 보기만 합니다. 상품을 지우면 적용 상품에서도 같이 빠집니다.
  • 기간 없음 — 프로모션에는 기간이 없습니다. 활성 기간 · 사용 기간 · 선물 가능 · 중복 발급 제한은 쿠폰마다 정합니다. 신분 할인은 상태(활성 · 비활성)로만 켜고 끕니다.
  • 프로모션 비활성 — 이 프로모션의 쿠폰이 모두 멈춥니다(신분은 할인이 적용되지 않습니다). 다시 활성화하면 쿠폰은 각자 멈추기 전 상태로 돌아가고, 따로 꺼 둔 쿠폰은 계속 꺼져 있습니다. 이미 발급된 쿠폰은 사용 기간 안이면 그대로 쓸 수 있습니다.
  • 같은 프로모션의 쿠폰은 할인이 모두 같습니다 — 쿠폰마다 이름·이미지·기간만 다를 수 있습니다. 할인이 다르면 프로모션을 새로 만듭니다.
  • 크루 확인 — 신분 할인과 상품 교환권은 적용할 때 항상 크루 확인을 받습니다. 관리자가 켜고 끄는 설정은 없습니다. 확인 시점은 신분은 할인 적용 시, 교환은 교환(사용) 시입니다.
  • 크루 승인코드 — 크루마다 매일 새 코드가 자동으로 생깁니다. 크루 확인을 받을 때 크루가 입력하고, 누가 승인했는지 주문에 남습니다.
쿠폰 만들기 · 쿠폰 상세
  • 노출 정보(언어별) — 쿠폰명 · 이미지 · 설명을 한국어 / English / 中文 탭으로 따로 넣습니다. 한국어 쿠폰명은 꼭 넣어야 합니다.
  • 언어별 대신 보여주기 — 고객 언어의 값이 없으면 중국어 → 영어 → 한국어 순서로 대신 보여줍니다. 중국어가 없으면 영어, 영어도 없으면 한국어로 보입니다. 쿠폰명 · 이미지 · 설명 모두 같습니다.
  • 활성 기간 — 이 쿠폰을 발급할 수 있는 기간입니다. 사용 기간은 받은 쿠폰을 쓸 수 있는 기간입니다. 활성 기간이 끝나도 사용 기간 안이면 쓸 수 있습니다.
  • 쿠폰 활성/비활성 — 급하게 멈춰야 할 때 끄는 스위치입니다. 비활성화하면 새 발급만 막히고, 이미 발급된 쿠폰은 그대로 쓸 수 있습니다.
  • 발급 방식 — 난수번호(겹치지 않는 번호를 원하는 수량만큼, 접두어 가능), 프로모션 코드(공용 코드 입력 시 받기), 수동(회원 선택 또는 명단 CSV 업로드) 세 가지입니다. 저장한 뒤에는 바꿀 수 없어, 다른 방식이 필요하면 쿠폰을 새로 만듭니다.
  • 제휴는 보낼 대상을 지정할 수 없어 수동 발급을 쓸 수 없습니다. 3개월마다처럼 정기로 주려면 자동 발급 탭의 주기 기반에서 만듭니다.
  • 발급 수량 — 지정(숫자로 제한) 또는 무제한 중에서 고릅니다. 한도를 넣으면 다 나가는 순간 마감됩니다.
  • 선물 가능 · 중복 발급 제한 — 쿠폰마다 정합니다. 중복 발급 제한을 켜면 한 사람은 이 쿠폰을 한 장만 받습니다. 프로모션 코드는 이 설정과 관계없이 같은 코드로 한 사람당 한 장만 받습니다.
  • 선물 — 본인이 바로 쓰거나, 앱에서 휴대폰 번호로 지인에게 알림톡 + 딥링크로 선물할 수 있습니다. 받은 사람은 앱에서 등록해야 적용됩니다. 보낸 선물은 취소할 수 없고, 받기 전 대기 중인 쿠폰도 회수하거나 지우지 않습니다.
  • 알림 — 앱 푸시 · 알림톡을 먼저 보내고, 못 받으면 문자로 보냅니다. 저장 · 발급을 누르면 쿠폰 번호가 만들어지고 '발급됨'이 됩니다.
  • 쿠폰번호 엑셀 — 쿠폰 상세에서 발급된 쿠폰번호 전체를 엑셀로 받습니다.
쿠폰·이용 조회
  • 쿠폰 상세 — 쿠폰 한 장의 정보 · 소유 · 이력과 함께, 같은 쿠폰의 발급 · 사용 집계와 발급된 쿠폰 목록을 봅니다. 목록은 예시로 5장만 보여줍니다.
  • 환불로 되살아난 쿠폰 — 상태는 미사용으로 돌아가지만, 사용 기간이 이미 지났으면 쓸 수 없고 만료로 보입니다. 만료는 따로 상태로 두지 않습니다.
자동 발급
  • 사건 기반 — 가입 · 구매처럼 확실히 기록되는 일이 생기면 쿠폰을 줍니다. 쿠폰 내용은 연결한 프로모션을 따라가고, 같은 일로 같은 사람에게 두 번 발급되지 않습니다.
  • 환불 연동 — 시스템이 자동으로 처리해 보기만 합니다. 전체 환불은 쿠폰을 되돌리고, 부분 환불은 그대로 둡니다.
  • 늘리기 쉬운 구조 — 규칙은 '언제(트리거) + 무엇을(쿠폰 발급)' 조합으로 만들어집니다. 새 트리거를 추가하면 규칙도 바로 쓸 수 있습니다.
신분·제휴(자격)
  • 자격만 등록 — 이 탭에서는 이 사람·소속이 무엇에 해당하는지만 등록합니다. 할인율·쿠폰은 등록 후 프로모션에서 이 자격을 골라 만듭니다.
정하는 중
  • 사건 기반 자동 발급 전체 — 지금은 가입 · 구매 · 환불만 되고, 생일 · 자격 취득 트리거와 특정 상품 · 채널 · 자격 조건은 추가 개발이 필요합니다.

  • 교환 상품을 쿠폰에서 고를지 프로모션에 둘지 (개발팀 확인 중)
  • 쿠폰 이미지 규격, 저장 · 발급 후 안내 문구
