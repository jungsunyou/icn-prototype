  • 노출명: 한국어 필수 · 미입력 언어는 영문 대체
  • 종류: JAM = 이용권 차감 / 비JAM = 교환(개당 교환 차감)

  • PSU 코드는 저장 시 시스템이 자동 생성하는 유니크 키(외부 이용 처리·매핑 기준) · 수기 입력 아님 · 등록 후 변경 불가
  • 수정 시 종류·JAM유형·차감·코드는 변경 불가 · 이름·정가만 수정 (정의를 바꾸려면 신규 PSU로 등록)
  • 버전: 이름·정가 수정으로 저장 시 버전 +1 · 상품은 특정 PSU 버전을 참조 → 상품의 PSU 버전과 일치해야 함
  • 자원 연결(재고) · 이용 자격(연령·신장, 주니어 등) · 사용 처리(체크인·밸리데이션)는 각 소관 화면
