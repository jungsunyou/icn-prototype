목록
  • 판매 채널의 코드 · 이름과 연결할 카테고리를 관리합니다. 화면 구성은 개발 서버(2026-11-27 확인)를 옮긴 것이고, 값은 모두 예시입니다.
  • 여기 등록한 채널은 상품 관리의 판매 채널에 나옵니다.
기본 정보
  • 채널 코드는 등록할 때 직접 입력합니다. 저장한 뒤에는 바꿀 수 없습니다. 대소문자를 구분합니다(예: KLOOK과 klook은 다른 코드).
  • 이미 있는 채널 코드는 쓸 수 없습니다. 입력 칸을 벗어나면 바로 확인합니다.
  • 채널 유형은 고르지 않습니다. 코드와 이름, 연결 카테고리만 관리합니다.
카테고리 매핑
  • 카테고리 화면이 필요한 채널(앱 · 구매 키오스크 · OS 현장 구매)만 켭니다. 새 채널은 꺼진 상태로 등록됩니다. 끄면 연결한 카테고리가 모두 풀립니다.
  • 외부 채널(클룩 · 마이리얼트립 등)은 각 채널에서 직접 관리하므로 끕니다.
  • 카테고리 노출 순서는 모든 채널에 똑같이 적용됩니다.
기타
  • 채널 할인율은 이 화면에서 정하지 않습니다. 가격 정책 관리 > 채널 할인에서 정합니다.
  • 상품 판매 설정이나 외부 상품 매핑에서 쓰는 채널은 삭제할 수 없습니다.
