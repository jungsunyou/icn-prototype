안내
  • 티켓에 연결된 회원을 크루가 직접 연결하거나 끊습니다.
  • 고객 인증 없이 처리하는 점이 사후 매핑과 다릅니다.
  • 티켓 번호를 넣거나 NFC로 태그하면 매핑 정보가 보입니다.
  • 이전 닉네임은 매핑 전 임시 닉네임입니다.
  • 실명 · 전화번호는 보여주지 않습니다.
  • 해제는 연결을 끊고, 매핑은 강제로 연결합니다.
  • 회원 ID를 넣거나 회원을 고르는 단계는 없습니다.
  • 요청 유형: FIRST · MAPPING · FORCE_MAPPING · UNMAPPING
  • 요청 상태: REQUEST · ACCEPT · REJECT
  • 없는 티켓이면 '티켓이 존재하지 않습니다.'라고 알려줍니다.
정하는 중
  • 해제 · 매핑 때 확인 창이 뜨는지
  • 처리 뒤 바뀌는 값 (해제 → UNMAPPING · ACCEPT, 매핑 → FORCE_MAPPING · ACCEPT로 추정)
  • 매핑할 회원을 정하는 방법 (지금은 표의 회원)
  • '티켓이 존재하지 않습니다.' 안내 모양
  • REQUEST · REJECT · UNMAPPING 칩 색
