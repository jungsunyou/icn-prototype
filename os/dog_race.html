강아지레이스 예시 데이터

정하는 중 · 인천에서 강아지레이스를 할지, 한다면 어떻게 할지 아직 정하지 않았습니다. 화면 전체가 제주 구성을 옮긴 예시입니다.
안내
  • 댕댕레이스(반려견)와 촉감레이스(사람)를 같은 방식으로 운영합니다.
  • 순서: 티켓 번호 등록 → 이름 등록 → 10초 카운트다운 → 레이스 → 기록.
  • 위쪽 막대 4칸이 지금 단계를 보여줍니다.
  • 티켓 번호는 13자리를 넣거나 NFC로 태그합니다.
  • 레이스가 끝나면 티켓 사용 처리로 사용 처리할 반려견(참가자)을 고릅니다.
  • 기록 관리에서 날짜별 기록을 보고, 티켓 취소 처리로 여러 건을 골라 취소합니다.
  • 구성은 제주 실서비스, 단계별 화면은 2026-06 강아지레이스 프로토타입을 따랐습니다.
정하는 중
  • 인천에서 강아지레이스를 할지, 어떻게 할지 (화면 전체)
  • 영상 테스트 버튼 동작
  • 영상 상태 값
  • 사용 처리 · 취소 뒤 안내 문구
  • 촉감레이스 참가자 이름에 실명을 받을지 (개인정보 기준)
