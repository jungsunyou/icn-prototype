안내
  • 티켓 No(NFC ID) · 예약번호 · 주문번호 · 닉네임으로 찾아요.
  • 이름 · 전화번호 · 이메일 · 카드번호로는 찾지 않아요.
  • 고객은 닉네임으로만 보여줘요.
  • 검색 일시 기준은 예약(이용일)과 주문(결제일) 중에서 골라요.
  • 상태는 이용일과 PSU 이용 여부로 자동으로 정해져요.
  • 예약 → 이용 중 → 이용 완료 / 만료 / 부분 만료
  • 환불 처리 중 → 환불 · 부분 환불 / 환불 실패
  • 예약번호를 누르면 예약 상세가 열려요.

안내
  • 예약자 정보는 주문 구분과 닉네임만 보여줘요.
  • 주문 내역은 티켓 한 장이 한 줄이에요.
  • 티켓을 골라 환불 확정하거나, 주문 단위로 전체 환불해요.
  • '환불 확인'을 누르면 그 티켓의 PSU(JAM) 사용 내역이 펼쳐져요.
  • 제공 · 이용 · 남음은 확정 데이터예요.
  • 인천은 1인 1티켓이라 레이서 분리 · 병합은 없어요.
  • 발권하기 → 로봉이 NFC 칩 태그 → 연동하면 발권돼요. 여러 장은 한 장씩 차례로 태그해요.
  • 이미 다른 티켓에 연결된 로봉이는 연동하지 않아요. 재발권은 새 로봉이를 태그해 바꿔요.
  • 금액 수정은 사유와 함께 결제 금액을 바꿔요. 차액은 재결제로 처리해요.
  • 재결제는 기존 결제를 취소하고 새 금액으로 다시 결제해요.
  • 거래 이력은 결제 · 부분 취소 · 재결제 기록이에요.
  • 처리 이력에는 취소 · 환불 · 발권 기록과 크루 메모가 쌓여요.
  • 매출 금액 = 결제 금액 − 환불 금액이에요.
정하는 중
  • 환불 금액 계산 규칙 (미사용 PSU를 나누는 기준)
  • 금액 수정 · 재결제를 어디까지 허용할지
  • 로봉이 연동 전체: 대상 상품 · 인원, 번호 형식(예시 RB-0123), 확인 단계 여부, 창 제목 · 안내 · 버튼 문구, 발권 취소 · 환불 때 연결 풀기, 티켓 NFC와 관계
