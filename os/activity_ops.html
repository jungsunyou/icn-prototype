게임 목록
정하는 중 · 보라색 칸(랭킹 · 스코어 · 킬 · 데스 · 랩타임)은 액티비티별 기록 칸이 확정되면 반영합니다. 지금은 하레나 · 왕의동굴에 킬 · 데스, 디지털레이스에 랩타임을 넣어 둔 안입니다.
안내
  • 공간 → 액티비티를 고르고, 운영 관리 / 기록 관리를 바꿔 봅니다.
  • 수동 추가: 티켓 번호 13자리 입력. 인원 추가: NFC 태그.
  • 매치에 넣으면 장비를 골라 연결하고, 상태는 대기중이 됩니다.
  • ✕를 누르면 장비 연결을 풀고 매치에서 빠집니다.
  • 게임 시작 → 게임중, 게임 종료 → 확인 후 기록이 생깁니다.
  • 티켓 사용 처리: 사용 처리가 안 된 티켓을 크루가 직접 처리합니다. 누르면 매치 정보에 체크박스가 생깁니다.
  • 장비 상태는 직접 바꾸거나 AI 상태 반영에 운영방 메시지를 붙여 넣으면 바뀝니다.
  • 장비 번호를 누르면 그 장비의 수리 이력이 보입니다.
  • 고장 → 고장 기구 · 메모 → 확인하면 "[고장] 상태로 변경되었습니다."가 뜨고 수리요청이 됩니다.
  • 수리요청 · 수리중 장비는 운영 · 충전으로 바꿀 수 없습니다.
  • 수리는 통합 장비 관리에서 처리합니다.
정하는 중
  • 공간 → 액티비티 2단 선택
  • 장비 번호 형식, 액티비티별 고장 기구 이름
  • 운영 · 충전으로 바꿀 때 안내 문구 (지금은 고장과 같은 형식)
  • 대기 → 매치 자동 넣기 (인천)
  • 기록 점수 칸 (랭킹 · 스코어 · 킬 · 데스 · 랩타임)
  • 사용 처리 뒤 안내 문구, 빈 매치에서 게임 시작
  • AI 상태 반영 창 모양과 알아듣는 문장 범위 (GR 정비 관리 방식 적용)
✦ AI 상태 반영 · 운영방 메시지로 상태 반영 (정하는 중 · 예시)
